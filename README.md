## 🇮🇹 Italiano

**Image Tag Manager** è uno strumento potente e intuitivo progettato per gestire, modificare e generare automaticamente tag per le tue immagini. Ideale per la preparazione di dataset per l'addestramento di modelli AI (Per esempio immagini su CivitAI, Kohya_SS o similari)

### Cosa puoi fare:
*   📂 **Caricamento Cartelle**: Importa intere cartelle contenenti immagini e i rispettivi file di testo (`.txt`) associati.
*   🏷️ **Gestione Tag Semplificata**: Aggiungi, rimuovi o modifica i tag per singole immagini o per gruppi di immagini (Bulk Tagging).
*   🤖 **Auto-Tagging con Intelligenza Artificiale**: Genera automaticamente i tag per le tue immagini utilizzando un modello AI locale (privacy-first, nessuna connessione internet richiesta). Puoi usarlo su singole immagini o su tutto il progetto contemporaneamente.
*   🌍 **Gestore Tag Globale**: Visualizza e gestisci tutti i tag presenti nel progetto da un'unica comoda interfaccia. Aggiungi "Trigger Words" globali a tutte le immagini con un clic.
*   💾 **Esportazione Flessibile**: 
    *   Salva le modifiche sovrascrivendo i file `.txt` originali (ideale per la modalità portatile).
    *   Esporta tutto in una nuova cartella.
    *   Salva l'intero progetto come archivio `.zip`.
*   🎨 **Temi e Personalizzazione**: Scegli tra Tema Chiaro (Day) e Tema Scuro (Night).
*   🌐 **Multilingua**: Supporto per Italiano, Inglese, Francese, Spagnolo e Tedesco.

## 🇬🇧 English

**Image Tag Manager** is a powerful and intuitive tool designed to manage, edit, and automatically generate tags for your images. Ideal for preparing datasets for AI model training (like LoRA or Stable Diffusion) or simply organizing your gallery.

### Features:
*   📂 **Folder Loading**: Import entire folders containing images and their associated text files (`.txt`).
*   🏷️ **Simplified Tag Management**: Add, remove, or edit tags for individual images or groups of images (Bulk Tagging).
*   🤖 **AI Auto-Tagging**: Automatically generate tags for your images using a local AI model (privacy-first, no internet connection required). Use it on single images or the entire project at once.
*   🌍 **Global Tag Manager**: View and manage all tags present in the project from a single convenient interface. Add global "Trigger Words" to all images with one click.
*   💾 **Flexible Export**: 
    *   Save changes by overwriting the original `.txt` files (ideal for portable mode).
    *   Export everything to a new folder.
    *   Save the entire project as a `.zip` archive.
*   🎨 **Themes & Customization**: Choose between Light (Day) and Dark (Night) themes.
*   🌐 **Multilingual**: Support for Italian, English, French, Spanish, and German.
